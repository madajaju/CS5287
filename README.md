## Course Description

CS5287 is an applied exploration of modern cloud systems. The course moves from cloud foundations, virtualization, and
infrastructure as code through containers, Kubernetes, reliability engineering, serverless and edge computing,
distributed storage and data processing, AI workloads, and next-generation networking.

Hands-on cloud assignments develop deployment, automation, scaling, observability, resilience, and multi-hybrid-cloud
skills. Generative AI is used throughout as a learning and engineering tool: students use it to explore concepts,
create and debug systems, and prepare technical communication while verifying its output, documenting its use, and
retaining responsibility for the final work.

Documentation, lecture materials, and assignments can be found in the respective folders.
