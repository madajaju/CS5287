== Topics of Study

---

== Course Journey

- Build one reference stack across CA0–CA4
- Move from manual deployment to infrastructure as code and orchestration
- Add scaling, observability, security, and resilience
- Extend the system across multiple sites or clouds
- Use GenAI throughout, verify its output, and preserve evidence in the Integrity Packet

---

== Weeks 1–4: Foundations to Containers

- *Week 1:* Cloud computing, cloud enablers, opportunities, and REST
- *Week 2:* Operating systems, processes, memory, networking, message brokers, and Kafka
- *Week 3:* Virtualization, IaaS, OpenStack, infrastructure as code, Ansible, and Terraform
- *Week 4:* Containers, container networking and orchestration, Docker, and Docker Swarm

---

== Weeks 5–8: Orchestration and Reliability

- *Week 5:* Kubernetes architecture, networking, and service mesh
- *Week 6:* Cloud load balancing, Kubernetes scheduling, and scaling
- *Week 7:* Observability in the cloud, SRE components, and tail latency
- *Week 8:* Chaos engineering

---

== Weeks 9–12: Distributed and AI Workloads

- *Week 9:* Edge computing, overlay VPN, and serverless computing
- *Week 10:* Data partitioning, sharding, and distributed file systems
- *Week 11:* MapReduce, Apache Spark, and Apache Ray
- *Week 12:* GPU architectures, LLM serving, and agentic workflows

---

== Weeks 13–14: Networking and Demonstration

- *Week 13:* Software-defined networking, network functions virtualization, and 5G
- *Week 14:* Individual final project demonstration and technical defense
- Defend architecture choices with logs, metrics, tests, and Integrity Packet evidence
